# ShivFlow

ShivFlow is a fast, buttery-smooth YouTube client for Android by Shivyt —
built for instant playback, background play, downloads and a clean,
distraction-free Material 3 interface.

## Highlights

- Instant, buttery playback with adjacent preloading (Media3)
- Background audio and picture-in-picture
- Offline downloads with quality and format choice
- SponsorBlock, Return YouTube Dislike, DeArrow
- Sign in with your Google account through Shivyt GmsCore
- Local recommendations, no account needed
- Music mode with lyrics

## Packages

- App: `shivyt.android.flow`
- Companion Google services: Shivyt GmsCore (`shivyt.android.gms`)
